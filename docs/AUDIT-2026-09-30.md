# Deep Audit — 2026-09-30

Three parallel audits: **frontend** (Mini App), **backend** (bot), **security**. 53 findings total. All Critical and High findings fixed same-day; bot restarted, 10/10 smoke groups passing.

## Frontend (4 Critical, 6 Major, 8 Moderate, 7 Minor)

| # | Finding | Fix |
|---|---|---|
| C1 | Cart silently wiped on app open (CloudStorage/catalog race) | `pruneCart` gated on catalog readiness |
| C2 | Wishlist never restored (same race) | Deferred validation via `pruneWish` |
| C3 | `sendData` closes the Mini App — "Notify me" killed the app | Alerts queue locally, piggyback on checkout |

| M1 | Sheet close/open race | Timeout ID tracked + cleared |

| M3 | TON sender not in user-friendly format | `toUserFriendlyAddress()` conversion |
| M5 | "Check the bot chat" toasts never seen | Shown before `sendData` with delay |
| M6 | Full re-render per keystroke | 150 ms debounce |
